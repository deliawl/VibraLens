Pertanyaan

Sering Ditanyakan

Apa itu metode HVSR?

HVSR (Horizontal-to-Vertical Spectral Ratio) adalah metode analisis mikroseismik yang memanfaatkan sinyal ambient noise untuk mengestimasi frekuensi dominan (f₀) dan amplifikasi (A₀) lapisan tanah. Diperkenalkan oleh Nakamura (1989).

Apa arti f₀, A₀, dan K_g?

f₀ adalah frekuensi dominan (Hz) — frekuensi natural tanah. A₀ adalah amplifikasi (rasio) — seberapa besar getaran diperkuat. K_g = A₀²/f₀ adalah indeks kerentanan seismik (Kanai).

Bagaimana cara membaca zona kerentanan?

K_g < 3 = aman, 3–10 = sedang, > 10 = rawan. Nilai K_g tinggi berarti tanah lebih rentan terhadap amplifikasi goncangan gempa.

Seberapa sering data di-update?

Data sensor dikirim setiap 10 detik. Analisis HVSR dilakukan per window 30 menit untuk stabilitas statistik.

Siap memetakan kerentanan seismik kampus?

Semua parameter HVSR terintegrasi dalam satu dashboard. Mulai eksplorasi sekarang.

Tentang VibraLens

Latar Belakang

VibraLens dikembangkan sebagai bagian dari tugas akhir Program Studi Geofisika, Universitas Padjadjaran, untuk menganalisis kerentanan seismik kawasan kampus Jatinangor menggunakan metode HVSR berbasis IoT.

Tujuan

Mengestimasi parameter f₀, A₀, dan K_g dari sinyal ambient noise untuk microzonasi seismik kawasan kampus.

Cara Kerja

Geophone → Node LoRa → Gateway LTE → Server → Analisis HVSR → Dashboard.
