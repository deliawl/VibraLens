Panduan Pengguna

Pelajari cara menggunakan setiap modul VibraLens untuk pemantauan dan analisis getaran tanah.

Daftar Isi
Memulai Beranda Katalog Data Peta & Jaringan Analisis Sinyal Monitoring Event & Alarm Riwayat & Ekspor

Memulai

VibraLens adalah sistem pemantauan getaran tanah berbasis IoT dengan analisis Horizontal-to-Vertical Spectral Ratio (HVSR) untuk microzonasi seismik. Sistem ini dikembangkan untuk kawasan Universitas Padjadjaran Jatinangor.

Yang Anda Butuhkan

  • Browser modern (Chrome, Firefox, Edge, Safari versi terbaru)
  • Koneksi internet (untuk fitur peta & data lingkungan satelit)
  • Resolusi minimal 1366×768 (desktop) atau mobile

Navigasi Utama

Semua modul bisa diakses dari menu drawer (klik ikon ☰ di kiri atas) atau dari footer di bawah halaman.

Beranda

Halaman utama menampilkan ringkasan sistem secara real-time:

Ringkasan Sistem Jumlah node aktif, PGV maksimum, dan update terakhir
Parameter HVSR Rata-rata f₀, A₀, dan K_g semua node + kurva HVSR
Fitur Tersedia Akses cepat ke 7 modul VibraLens
Alur Sistem Penjelasan tahapan dari sensor ke dashboard

Katalog Data

Katalog berisi daftar lengkap semua node VibraLens beserta metadata: identitas alat, lokasi, data stream, dan informasi kepemilikan.

Cara Menggunakan

  1. Buka menu Katalog Data
  2. Gunakan search box untuk cari berdasarkan kode, nama, atau model
  3. Filter by status: Aktif, Zona Aman, atau Zona Rawan
  4. Klik kartu node untuk melihat detail metadata lengkap

Metadata yang Tersedia

Identitas AlatModel, serial number, jumlah kanal
LokasiKoordinat, elevasi, deskripsi
Data LingkunganSuhu, kelembaban, hujan (satelit)
KepemilikanKode katalog, pemilik, lisensi

Peta & Jaringan

Visualisasi lokasi semua node pada peta interaktif.

Fitur

  • Zoom & pan — scroll untuk zoom, drag untuk pindah lokasi
  • Filter status — tampilkan hanya node dengan status tertentu
  • Klik marker — popup dengan informasi lengkap node
  • Tombol "Lihat Metadata Lengkap" — arahkan ke halaman detail

Warna Marker

Online — semua normal
Sinyal Lemah — PGV 0.5–1.0 mm/s
Alert — PGV > 1.0 mm/s
Offline — tidak ada data >60s

Analisis Sinyal & AI

Modul inti VibraLens — jalankan analisis HVSR otomatis dari data waveform node.

Langkah Analisis

  1. Pilih node dari dropdown
  2. Pilih durasi analisis (10/30/60 menit)
  3. Klik Jalankan Analisis
  4. Tunggu proses (preprocessing → FFT → HVSR → AI)
  5. Lihat hasil: kurva HVSR + parameter + interpretasi AI

Yang Anda Dapatkan

Kurva HVSRRasio H/V dalam domain frekuensi
f₀ (Hz)Frekuensi dominan tanah
A₀Faktor amplifikasi
K_gIndeks kerentanan Kanai

Catatan: Saat ini data waveform untuk analisis dihasilkan secara sintetis (dummy) yang menyerupai karakteristik HVSR target setiap node. Ketika sensor fisik terpasang, pipeline analisis akan otomatis menggunakan data real.

Monitoring Real-Time

Dashboard live yang memperbarui data setiap 5 detik.

Isi Halaman

  • Status bar — LIVE indicator, jumlah node aktif, waktu update
  • Grid kartu node — PGV terkini setiap node + f₀ & A₀
  • Chart PGV agregat — tren 6 jam terakhir

Halaman ini otomatis refresh. Tombol Refresh di kanan atas untuk manual update.

Event & Alarm

Log kejadian penting: alert, sinyal lemah, offline, dan koneksi kembali.

Filter

  • By Node — tampilkan event dari node tertentu
  • By Tipe — Alert / Warn / Offline / Online

Summary Card

Di bagian atas ada 4 kartu yang menunjukkan total event per tipe (Alert, Sinyal Lemah, Offline, Online).

Riwayat & Ekspor

Telusuri data historis node berdasarkan rentang tanggal dan ekspor ke CSV.

Cara Ekspor

  1. Pilih node
  2. Tentukan rentang tanggal (opsional)
  3. Klik Export CSV
  4. File CSV otomatis ter-download

Isi File CSV

Kolom: timestamp, node_id, PGV, PGA, frekuensi dominan, RMS, 3 kanal getaran, curah hujan, kelembaban, suhu, tekanan, status.
